    HOW I start this website

    網站由來  //  MARCH 4, 2021

    空格字元
    專門為初學者打造
    目前網路上有許多關於攝影教學的文章，但因為缺乏基本的知識，在這些龐大資訊中難以找到方向；又因只有手機沒有專業相機，不僅降低了學習興趣，也扼殺了許多想學攝影的初學者，因此我想藉由這個網站，讓初學者也能有系統的學習攝影，從基本概念到拍攝技巧，後製等一併學起來，之後也可以拍出優質的照片。

    貼心的學習速度
    由於我也是攝影領域入門，為了配合學校教學進度，本網站為每周一更，跟著我一起從零開始學習拍照或攝影等知識。每一個單元皆具有詳細的文字介紹，網站底部也有優秀攝影作品網站連結，在閒暇時觀看優秀的攝影作品，說不定會引發更多的創意思考，進而在攝影領域上擁有自己獨特的風格。
