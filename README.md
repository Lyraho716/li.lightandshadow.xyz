# 栗光見影：GitHub Pages 搬家檔案

本檔案由已登入的 Weebly 編輯器預覽備份，沒有在 Weebly 發佈。

包含 9 個頁面、周記目前顯示的 4 篇文章、圖片與網站主題樣式。首頁為 index.html。已修正主要導覽與首頁延伸閱讀按鈕，並保留舊頁面檔名的相容版本。

部署：把本資料夾內的檔案（包含 assets 資料夾與 .nojekyll）上傳到你的 GitHub Pages 儲存庫，在 Settings → Pages 選擇要發佈的分支與根目錄。若要使用 username.github.io，儲存庫名稱須對應你的 GitHub 使用者名稱。

限制：這是靜態搬移版本，不包含 Weebly 後台、資料庫、留言與表單收件功能。周記回饋表單需另接收件服務；Widgetic 元件未能離線保存。部分編輯器版面與圖庫互動已改成靜態展示，請先檢查內容與圖片再發佈。圖片與文字保留原內容；未驗證教學資訊的正確性。
